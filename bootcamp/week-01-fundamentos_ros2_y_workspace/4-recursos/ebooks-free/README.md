# 📚 Ebooks y guías gratuitas — Semana 01

| Recurso | Por qué vale la pena |
|---|---|
| [ROS2 Jazzy Documentation (docs.ros.org)](https://docs.ros.org/en/jazzy/) | La fuente de verdad de todo el bootcamp. Descargable como sitio estático para consulta offline vía su repositorio en GitHub (`ros2/ros2_documentation`) |
| [REP 2000 — ROS2 Releases](https://ros.org/reps/rep-2000.html) | Explica el ciclo de releases de ROS2 y por qué Jazzy es la LTS vigente — útil para entender por qué el bootcamp fija esta versión |
| [Programming Multiple Robots with ROS 2 (libro gratuito online)](https://osrf.github.io/ros2multirobotbook/) | Aunque el título dice "multi-robot", sus primeros capítulos son la mejor introducción gratuita al grafo computacional y `rclpy`/`rclcpp` en paralelo — exactamente el enfoque de esta semana |
