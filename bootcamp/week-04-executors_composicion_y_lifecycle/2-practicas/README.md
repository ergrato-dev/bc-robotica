# Prácticas — Semana 04

Cuatro ejercicios guiados:

| # | Ejercicio | Lenguaje | Qué construye |
|---|---|---|---|
| 01 | [`ejercicio-01-callback_groups_py`](ejercicio-01-callback_groups_py/README.md) | Python (`rclpy`) | Nodo `monitor`: un timer que sigue latiendo mientras un servicio lento trabaja |
| 02 | [`ejercicio-02-componente_cpp`](ejercicio-02-componente_cpp/README.md) | C++ (`rclcpp`) | El mismo `monitor` como componente, cargado en dos containers para justificar el executor |
| 03 | [`ejercicio-03-lifecycle_py`](ejercicio-03-lifecycle_py/README.md) | Python (`rclpy`) | Driver simulado `range_driver` como nodo lifecycle |
| 04 | [`ejercicio-04-lifecycle_cpp`](ejercicio-04-lifecycle_cpp/README.md) | C++ (`rclcpp`) | El mismo driver lifecycle en C++, también como componente |

Haz el 01 antes que el 02 y el 03 antes que el 04: el segundo de cada pareja
repite el nodo en el otro lenguaje y compara. El 01 y el 02 necesitan las
teorías 01 a 03; el 03 y el 04, la teoría 04.
